# FlexChroma Documents

このフォルダには、**FlexChromaで公開しているPDFドキュメント**を収録しています。

製品・フィラメントの使い方、各種ガイド、リファレンス資料など、第三者が閲覧・利用することを前提とした公開版です。  
内容を確認する場合は、原則としてこのフォルダ内のPDFを参照してください。

## Documents

主に以下のような資料を収録しています。

- FlexChroma各ラインの利用ガイド
- Blend / Gradientなどのフィラメント関連資料
- Color Checkerなどのリファレンス資料
- FlexChroma Tour Guide
- その他、FlexChromaを利用するための補助資料

資料は必要に応じて更新されます。  
同じ内容の文書が複数ある場合は、**より新しいRevisionまたは更新日のものを優先**してください。

## Languages

資料は、日本語・英語・ドイツ語など複数の言語で公開している場合があります。

ファイル名に言語を示す表記が含まれている場合は、以下を目安にしてください。

- `JP` / `JA` : Japanese
- `EN` : English
- `DE` : German

すべての資料がすべての言語に対応しているわけではありません。

## Original Files

[`Original`](./Original/) フォルダには、PDF作成前の**編集用データおよび文書作成用の資料**を保存しています。

これらは制作・更新作業のためのファイルであり、公開版PDFと内容やレイアウトが異なる場合があります。  
FlexChromaの資料として参照する場合は、**この `Documents` フォルダ直下にある公開版PDFを優先してください。**

# About This Folder

This folder contains the **published PDF documentation for FlexChroma**.

The documents are intended for public use and include product guides, filament-related documentation, reference materials, and other resources for using FlexChroma.

When referring to FlexChroma documentation, please use the published PDF files in this folder unless otherwise noted.

## Languages

Some documents are available in multiple languages, including Japanese, English, and German.

Language identifiers in filenames may include:

- `JP` / `JA` : Japanese
- `EN` : English
- `DE` : German

Not every document is available in every language.

## Original Files

The [`Original`](./Original/) folder contains **editable source documents and production materials** used to create the published PDFs.

These files may differ from the current published versions in content or layout.  
For general reference, please use the published PDF files located directly in this `Documents` folder.
