## Document Rules

## Brand Typeface

FlexChromaのドキュメントでは、欧文の基本書体として **Jost**、日本語の基本書体として **Noto Sans JP** を使用します。Jostの幾何学的で柔らかな字形と、Noto Sans JPの癖が少なく読みやすい字形を組み合わせることで、欧文・日本語の双方で統一感のある見た目を維持します。

ブランド名は **Jost SemiBold** を使用します。FlexChroma、ColorCore、ModelCoreなど、ブランドまたはプロジェクトを示す名称はSemiBoldで統一し、本文中でもブランドとして明確に認識できる強さを持たせます。

FlexChroma配下の製品名・ライン名には **Jost Medium** を使用します。Blend Filament、Gradient Filament、TriBlend Filamentなどが該当します。ブランド名と製品名を連続して表記する場合は、**FlexChromaをJost SemiBold、製品名・ライン名をJost Medium** とし、文字の太さによってブランドと製品の階層を表現します。

例：**FlexChroma** Blend Filament

## Brand Color

ブランドの代表カラーはマゼンタとシアンのグラデーション。彩度を保つために紫を経由する。各色の詳細は下表の通り。グラデーションは60度傾いた状態とし、左斜め上のマゼンタから中央の紫を経由し、右斜め下のシアンへつながる。マゼンタとシアンはグラデーションの端でなくともよい。紫も完全な中央でなくともよい。

この色はアイコンやドキュメントのブランドカラーとして用いる。

| Color name | HEX Value |
| ---------- | --------- |
| Magenta    | #EE00B0   |
| Purple     | #6200E8   |
| Cyan       | #0095E5   |
